3. Tinycharts — a skill, not a SaaS

site · tweet · product design

Sources. tinycharts · launch tweet

Mechanism. A Claude skill that turns "how does X work" into one hand-drawn isometric HTML sheet. What makes it worth $34.90: a real statechart behind the buttons — disallowed moves are refused with a reason. 9 types free, 28 paid. Sells a ZIP, not a server.

Taken. The "legend is the product" idea went into tabel's chart cards (mapping + query), and the tone of kurator. Ignored. The drawing kit; that is months of taste, not a weekend.

5. Details.so — taste as an MCP

details.so/mcp · distribution product

Source. details.so/mcp

Mechanism. A curated UI library (3,500+ references, code in a "Vault") exposed as a remote MCP server with OAuth (Supabase) and credit metering (X-Details-Credits-*). Sold with every paid plan. Install is one command per client.

Taken. The product shape for kurator: a narrow, curated, callable library with opinions and a jangan list. The positioning: *"your AI can generate, but it doesn't know what good looks like."* Ignored. OAuth and credits at this scale; a bearer token and a rate limit are enough until strangers depend on it.

15. The content factory is a kanban board

tweet · 2026-11-16 · product distribution video

Mechanism. *"Video editing is following the same path AI coding took in 2025–26. The 10×–100× programmers don't write code anymore. They build software factories."* The screenshot is the claim made concrete: a board for a kids' puppet show — 107 items, stages Idea → Script → Voicing → QC → Kit ready → Approved → Partly posted → Posted, 80 approved and waiting, 14,441 views tracked, one fully finished. The asset is not the video; it is the pipeline that turns an idea into a posted short without a meeting.

The second image is the adoption curve: video ~9 months behind code, dotted line crossing above today's point.

Taken. Honestly: not built yet, and it names the gap. studio makes one artefact per prompt — sprite, loop, ASCII, stack — then forgets it. There is no queue, no review state, no record of what was exported or where it went. The board says the product is the *batch*: draft → generated → approved → exported → shared, with a platform check per item. That is the next feature, not this one.

Ignored. The niche and the volume (puppets, 100+ episodes). Volume without a channel is inventory; we have no channel to feed.

27. Sprites as game assets, not pictures

PixelLab · product generation

Mechanism. AI pixel-art generation built around game production: 4/8-direction characters, one-click/skeleton/text-driven animations, sheet export, Aseprite extension, Pixelorama in the browser, MCP/API, subscription. The unit is a *state* (idle, walk, attack), not an image.

Taken. The provider adapter should expose "animation state" and "sheet", not "image". The editor consumes both; generation is replaceable. Do not compete on generation.

Ignored. Subscription and game-engine tooling. We are the scene after the sheet.

28. Animation is a request with a start frame

Retro Diffusion · product generation

Mechanism. Pay-per-image API ($0.03–0.18) with animation styles that take input_image + motion and return a GIF or return_spritesheet: true; palette input, transparent output, native-grid constraints (32–256px, pad before animating, retry once).

Taken. The shape of the request (image + motion + frames + return_spritesheet) and the three failure rules. This is the cheapest credible animation provider for Phase 2.

Ignored. Prepaid credits and the prompt-driven styles we cannot verify.

29. Consistency comes from a character model

Scenario — Action Sprite Studio · product generation

Mechanism. One character image → a 12-frame sprite sheet; custom character models trained on 5–15 references keep proportions and palette across idle/walk/attack; paid plans carry commercial rights.

Taken. Sell consistency, not a single sprite. If a buyer needs three states, the model (or a human) must hold the character; our scene then holds the motion.

Ignored. The video-generation pipeline and the credit plans.
