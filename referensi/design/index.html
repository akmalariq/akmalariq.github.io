4. Painted Houses — a painting rebuilt as a house

site · design

Mechanism. Four paintings, each turned into an isometric building in the painting's palette, with a legend that maps the elements (turban → pantile roof, pearl → gable window). No 3D library: SVG, one fixed camera, one fixed light, painter's algorithm by hand.

Taken. Every chart in tabel now carries its mapping in words, not only a picture. Ignored. Hand-built isometric scenes; too expensive for a data tool.

6. ClairEmu — Linux in the browser

emu.kadcom.dev · design engineering

Mechanism. Debian 13 on RISC-V 64 in the browser via TinyEMU + WebAssembly; COOP/COEP and SharedArrayBuffer; WebGPU ("Suar · Vulkan"), WebGL ("Pelita · OpenGL"), 2D canvas; CRT/STN screen effects; five languages; explicit "beta, your data may be lost".

Taken. Renderer choice as a user-facing control instead of a hidden fallback; honesty in the beta banner. Ignored. Client-side compute. Our work is small; the server is the right place for it.

19. Components are outputs; behaviors are the product

ui-sdk.dev · seen 18 Nov 2026 · design product distribution

Mechanism. Do not give an agent a Select component. Give it the pieces a Select is made of — createPopup (open, position, dismiss), createSelection (pick one or many), createTypeahead (type to jump) — and it can build a select, an autocomplete, a combobox, or a component nobody has thought of yet. UI SDK ships 50+ of these behaviors and a component library built from them, across React, Vue, Svelte, Solid and Web Components.

The named primitives are the useful part:

BehaviorJob
createRovingFocusarrow keys move through a list, one Tab stop
createTypeaheadtype a few letters to jump to an item
createPopupopens next to its button, stays on screen
createSelectionpick one or many, Shift/Ctrl like a file manager
createReordersort a list with pointer or keyboard
createResizeresize boxes from their handles
createViewportpan and zoom a canvas
createVirtualizerrender only the rows you can see

The page's own line is the thesis: *"How do I use behaviors to build components? You don't. Ask your agent."* That is a product decision, not a docs shortcut.

Taken. The vocabulary for kurator: package a pattern as a named behavior with a contract (what it does, its states, its keyboard rules), not a screenshot or a block of HTML. The prompt then tells the agent which primitives to compose. This is the same move as Transitions.dev's skill, one level lower: from components to interaction primitives.

Ignored. Adopting the SDK. But "name the reusable interaction, not the component" is now a rule; it is also why the notes here are filed under *mechanism* instead of *link*.

20. One file, no dependencies, installed by the agent

affectui.com · seen 18 Nov 2026 · design product distribution

Mechanism. 221 React components, screens, blocks, illustrations and motion effects for AI products. Every item is one .tsx file with its styles inside — no Tailwind, no animation library, no other dependencies. Install with the shadcn CLI, or let Claude, Cursor or v0 do it through the MCP server. 74 items are free and MIT; the rest is Pro, one-time from $249.

Three choices worth copying:

Taken. For kurator: ship each pattern as a single self-contained file plus an install command, and treat the MCP server as the shop rather than the docs. The one-time pricing is a candidate for later — not before there is demand.

Ignored. React/tsx and the AI-product component set; our surfaces are server-rendered HTML and CSS by choice.

Cross-ref. This is the first entry where the shadcn CLI is the distribution channel. Fitfolio's DESIGN.md already borrows shadcn *as a contract* — semantic x / x-foreground token pairs, the radius scale, ring as a first-class token, eight interaction states — while explicitly rejecting the React/Tailwind implementation. Same separation, different layer: contract here, code there.

21. shadcn/ui — the component is a file you own

ui.shadcn.com · design product distribution

Mechanism. Not a dependency: the CLI copies component source into your repository, and from then on it is your code — editable, extendable, yours. The components sit on Radix primitives for behaviour and Tailwind for styling, but the unit that ships is a file, not a package. The docs are the product; the registry format now lets any CLI or agent install a component by name, which is why affectUI (entry 20) distributes through it.

Taken. Fitfolio's DESIGN.md already separates the two layers: it borrows shadcn as a contract — semantic x / x-foreground pairs, the radius scale, ring as a first-class token, eight interaction states, the component API names — and rejects the React/Tailwind implementation and a Next rewrite. For kurator, the registry is the model: ship the source plus an installable prompt.

Ignored. The React and Tailwind runtime. The contract survived without the code.

24. The manifesto is a set, not a document

human-md.ai · Briana (Mazzio) May · Apr 2026 · design product

What it is. A working manifesto — ten things humans bring when the models are good: break the rule on purpose (and say why), find the thing in the weird place, advocate for the human, design for resonance rather than correctness, seek delight, experiment ruthlessly, own the output, design *with* AI not beside it, play with purpose, be both builder and ideas person.

The mechanism. It calls itself "plain text, notes-to-self, not a deck" — and then delivers a staged set: a Klein-blue room with a person standing in it, a fern in a foot-shaped pot, an eye mug, giant type as scenery ("humans" in pink, cropped by the floor), one orange dot as punctuation. Scenes change worlds (blue → sage with two cups → mustard). Scroll is ~426,000px on desktop (≈500 viewports), smoothed with Lenis. The ## and ### headings are shown literally, as if the markdown were the set dressing.

The index is the best part. Not a table of contents: Polaroid cards with art-directed photos, one per section, numbered, fanned on a table. It makes a 500-viewport document navigable and worth looking at.

Taken.

  • Index as an object, not a list — the next version of /referensi should have a contact

sheet of notes (number, title, tag, one line), not only the chronological table.

  • One committed world per scene, one accent — useful for studio's modes, where each

medium (pixel, gerak, ASCII, stack) could own a palette instead of sharing one.

  • The rule-breaking test: if you cannot say why you broke the rule, you did not break it,

you missed. That is the same test as our "ignored" fields in this ledger.

Ignored. 500 viewports of scroll and a 3D/photo production budget. It is a portfolio piece; a calculator or a reference page has to be faster than it is beautiful. The text is also in the HTML source, so the "plain text" claim survives — but only if you view source.

25. Slop is a list you can audit

unslop-ui · Felipe Basurto · design copy

What it is. An Agent Skill that strips the AI look from interface and chart copy. The useful part is that "slop" is not a vibe: it is twenty numbered rules.

RangeWhat it catches
U1–U16Eyebrow labels, decorative 01 // numbering, subtitles that repeat the title, captions explaining the button, leaked design notes, Live · v2.4 · Synced status strings, label/placeholder/helper all saying "email", staccato slogans, fake NEW/AI badges, pulsing dots next to static data, decorative emoji, chart titles that name the chart, reading instructions, values said twice, chart scaffolding, legends a direct label could replace.
U17–U20 (opt-in --surface)Hue-to-hue gradients and glows, off-scale spacing, 800–900 weights, transition-all / hover:scale-* / animate-bounce.

Mechanism. Subtractive and safe by default: it touches visible text and decoration, never logic or data; it keeps aria-label, alt, visible form labels and anything tied to real state. Every run opens with a verdict — *heavy*, *light* or *none* (a clean screen is left alone) — and ends with a table of counts, Rewritten, Kept on purpose, and Tasks. The rewritten list is the only copy it wrote, so it is the part a human checks.

Taken.

  • The rule list is a review checklist, not a mandate. On duit, the small mono eyebrow ("THR", "Gaji bersih") is navigation in a five-tool suite; the H1 alone does not tell you which tool you are in. Delete it where it repeats the H1; keep it where it orients.
  • Tersimpan sementara is real state, so it survives U6; the three-day expiry now appears once, in the CTA. COBA DULU, TANPA AKUN is a real demo state too, not a decorative badge.
  • The report shape — counts, rewritten, kept, tasks — is the same discipline as the Ignored field in this ledger. A rule that changes nothing should say so.

Ignored. Running --surface across the suite: the Clay & Sand tokens, the chunky shadows and the 2.5px borders are deliberate, not slop. Deleting every label on every screen: context is a feature. And the skill's own precondition applies — do not run it on a screen with nothing to cut.
